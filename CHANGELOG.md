# История изменений

## Интерфейс «Маршрут»

- Главный экран с увеличенным таймером активного сбоя, цепочкой «Компьютер → Роутер → Интернет» и меткой проблемного этапа.
- Плавное скольжение между четырьмя разделами и сжатие чёрного подчёркивания при переключении.
- Движение точки при проверке, пульсация метки при сбое и анимированные разделители в трафике, журнале и оплате.
- Поддержка системной настройки анимаций Windows.

## v0.1.0

Первый предварительный релиз для Windows 10 x64.

- Диагностика по этапам: сетевой адаптер и Wi‑Fi, шлюз, доступ в интернет.
- Учёт текущей скорости и суточного трафика TCP/UDP по программам с помощью Windows ETW.
- Журнал отключений с оценкой длительности и выгрузкой текстового отчёта.
- Напоминание об оплате с выбранным сроком и опция автозапуска при входе в Windows.
- Задержка и число запросов без ответа до шлюза.

Архив содержит исходники и `Start.cmd` для сборки на Windows. Для включения учёта трафика нужны права администратора. Сборка и работа программы на Windows 10 ещё не проверены.
